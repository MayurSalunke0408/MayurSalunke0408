## Featured Projects

### Autonomous Campaign Builder - Multi-Agent GenAI System

Architected a LangGraph-based multi-agent workflow for automated marketing campaign creation.

- Connected OpenAI and Tavily for content generation and market research.
- Built prompt templates, tool calling, memory passing, retrieval, and guardrails.
- Added industry presets for automotive, insurance, and healthcare workflows.
- Integrated ChromaDB vector search for contextual knowledge retrieval.
- Stack: `Python` `LangGraph` `OpenAI API` `ChromaDB` `Tavily` `ReactJS` `Google OCR` `SMTP`

### Multi-Agent Document Intelligence System

Built a GraphRAG retrieval system over 500+ PDFs with strong semantic and graph-based search.

- Created a Neo4j knowledge graph from GPT-4 extracted entities and relationships.
- Processed unstructured PDFs with LLMSherpa and Docker to extract tables, text, and images.
- Implemented hybrid retrieval with vector search plus graph traversal.
- Automated ingestion and embedding workflows with LangChain and n8n.
- Stack: `Python` `LangChain` `LangGraph` `GPT-4` `LLMSherpa` `Neo4j` `ChromaDB` `AWS`

### Vegetable Market Price Forecasting - MLOps Pipeline

Developed a production-grade forecasting pipeline with statistical, ML, and deep learning models.

- Built ARIMA, SARIMA, Prophet, XGBoost, and LSTM forecasting models.
- Designed workflows for training, experiment tracking, retraining, and real-time inference.
- Created Power BI dashboards for monitoring and stakeholder decisions.
- Improved prediction accuracy by approximately 15% over baseline.
- Stack: `Python` `Scikit-learn` `XGBoost` `Prophet` `LSTM` `TensorFlow` `MLflow` `AWS` `Docker`
